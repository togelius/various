# Clack Stack (classic rules)

This is the version of Clack Stack before the rules were rebuilt from scratch. It is kept so the game can go back to it. It has:

- a clock that each finished level refills;
- levels named after things in the room;
- the crown and the cube SMASH;
- HOLD and OVERTIME;
- rings, a toy car and a foot that push the base;
- triangle braces (TRUSS);
- sway, and a plumb weight;
- dotted outlines for every legal spot.

`DESIGN.md` here is the design as it stood then (sections 1–16). Open `index.html` in a browser.

The tests in `tools/` drive this copy: `node clack-stack/classic/tools/selftest.cjs`, and so on.

The current game is one level up, in `../index.html`.
