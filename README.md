# various

A collection of small, self-contained projects. Each one lives in its own
subdirectory with its own README:

- **[vanguard-zero/](vanguard-zero/)** — VANGUARD ZERO, a 16-bit action
  platformer that runs in the browser. Open `vanguard-zero/index.html`, or
  grab the single-file build in `vanguard-zero/dist/`.
- **[annamatic/](annamatic/)** — ANNAMATIC, a five-minute playable vignette
  after the games of Anna Anthropy. One HTML file, no dependencies.
- **[ananke/](ananke/)** — ANANKE, a browser game of necessity: you cannot
  make anything happen, only make things impossible. Open `ananke/index.html`.
- **[roguelius/](roguelius/)** — Roguelius, a terminal roguelike about
  surviving NYU, written in Python.

## Repository policy

**All work in this repository happens directly on `main`.** No feature
branches, no long-lived side branches — every commit lands on `main`. The
former per-project branches were merged here and deleted. New projects get a
new subdirectory on `main`.
