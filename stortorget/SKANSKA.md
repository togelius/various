# Skånska phrasebook

The Skånska edition is written the way it sounds, a tad exaggerated. It is meant to be warm, rude and proud at once: Skåne humour loves a gentle insult. Interface copy stays readable; the shouts from the locals carry the heavy dialect. All game copy lives in `js/text.js` (and the wave names in `MODES.skanska` in `js/levels.js`).

## Voices

The mix runs from old Malmö to new Malmö:

- **Old Malmö and the countryside.** Edvard Persson (1888–1957) made the food-loving, good-natured Skåning a national type in films like *Söder om landsvägen* (1936); *Kvarteret Korpen* (Bo Widerberg, 1963) is working-class Malmö. In the game: kalops, spiddekaga, a bärs, rullebör, mölla, the rural insults.
- **The bridge.** Peps Persson sang blues and reggae in thick Skånska (*Hög standard*, *Oh boy*; covers titled *Styr den opp*). Hasse "Kvinnaböske" Andersson brings north-west Skåne. Tina Nordström brings the kitchen. In the game: *opp*, the diphthong spellings, the food.
- **New Malmö.** Zlatan's Rosengård and Timbuktu's Lund: Malmö youth language and Skånska forms like *himmelen*. In the game: *para*, *len*, *keff*, *jalla*, *wallah*, swagger.

## Spelling conventions

| Written | Standard | Why |
|---|---|---|
| jau | jag | diphthong, as in *"jau skolle vija hau…"* |
| haur, hau | har, ha | diphthong; from the Malmö FF slogan below |
| sitt | sett | as in the slogan |
| Malme, Malmes | Malmö, Malmös | as in the slogan |
| varden | världen | as in the slogan |
| dä | det | colloquial |
| e | är | colloquial |
| å | och / att | colloquial |
| mä | med | colloquial |
| te | till | colloquial |
| opp | upp | as in Peps Persson's *Styr den opp* |
| gador, kaga, närheden | gator, kaka, närheten | t → d, k → g, p → b softening between vowels |

**The slogan:** *Haur du sitt Malme haur du sitt varden* — "If you've seen Malmö you've seen the world", a 1980s *Sydsvenskan* slogan that Malmö stad cites as the classic example of Malmö speech. It is the intro's eyebrow line and an endless-wave name.

|---|---|---|
| påg | boy, lad | everywhere ("Kör, påg!") |
| tös | girl | — |
| glöttig | childish | "Du e glöttig, du!" |
| ålahue | idiot (lit. eel head) | shouts, wave 1, endless |
| ålarens | idiot (lit. eel offal), via Kalle Lind | shout |
| bonnaröv | country bumpkin (lit. farmer's arse) | shouts, endless |
| fubbick | idiot | shout |
| fjåne | fool | shout |
| klydderöv | someone who botches everything | shout |
| tjock i nacken | thick, stupid | shout |
| rälig | disgusting, ugly, frightening | shouts, endless |
| mög | dirt, muck, rubbish | lost run, map error, wave 3 |
| klyddig | awkward, fiddly | build tip |
| grina | to **laugh** (not cry, as elsewhere in Sweden) | "Jau grinar ihjäl mig!" |
| hutta | to throw | "Hutta'n i vannet!", gusts |
| asa | to drag | "Asa dig hem!" |
| hoe | head | towers, statue damage |
| flabb | mouth | "Spiddekaga i flabben!", ice cream |
| vann | water | shout |
| rullebör | wheelbarrow | the Danes go home *i rulleböre* |
| mölla | (wind)mill | gusts |
| spiddekaga | spettekaka, the Skåne tower cake | the mortar, the win screen |
| bärs | beer | the pickup, the support tower |
| kalops | beef stew, Persson-era comfort food | win screen, shout |
| Pågatåg | Skåne's regional trains | wave 5 |
| hörredu / hörru | "listen here" | tagline, shout |
| gött mos | great stuff | shout |
| fullt ös | full blast | maxed tower |
| para | money (Malmö youth slang) | the funds label |
| len | mate, bro (youth slang) | shout |
| keff | bad, rubbish (youth slang) | shout |
| jalla | come on, hurry (youth slang) | shouts |
| wallah | I swear (youth slang) | shout |

Words collected but not used yet: *tradig* (boring), *hialös* (impatient), *sylten* (hungry), *hiad* (craving), *eda* (eat), *pära* / *pantoffel* (potato), *stolpapäror* / *pinnapäror* (fries), *coca* (cola), *spann* (bucket), *alika* (jackdaw), *tåcke* (rooster), *märr* (mare), *glytt* (little boy), *grebba* (woman), *glojärn* (glasses), *uppåt landet* (anywhere north of Helsingborg), *spissflabbad* (talks posh, i.e. Stockholmer), *fjollträsk* (Stockholm, as a joke).
