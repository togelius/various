# Winter spruce

built-in OpenAI image-generation tool on 24 September 2026. Its RGBA alpha channel
is used as a cutout; it is not a screenshot or a photograph of a real location.

The original PNG is retained; `js/foliage-data.js` embeds it for offline play.
