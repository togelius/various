# Imported art assets

`js/assets.js` is generated by `tools/assets/import-glb.py` from `tools/assets/models.json`.
The models are converted to flat-shaded, vertex-coloured triangle lists (the colour map is
sampled per vertex) so the game needs no image files for them.

| Model in game        | Source file                                  | Kit                                   |
|----------------------|----------------------------------------------|---------------------------------------|
| ktruck (RANCHER)     | models/vehicle-truck-red.glb                 | Kenney Starter Kit Racing             |
| kmoto (HORNET)       | models/vehicle-motorcycle.glb                | Kenney Starter Kit Racing             |
| kbuildA..D, kgarage  | models/building-small-{a,b,c,d}.glb, building-garage.glb | Kenney Starter Kit City Builder |
| kfountain            | models/pavement-fountain.glb                 | Kenney Starter Kit City Builder       |
| ktrees, ktreesTall   | models/grass-trees.glb, grass-trees-tall.glb | Kenney Starter Kit City Builder       |

To regenerate: clone the two repositories, point the paths in `models.json` at them, then
`pip install pillow && python3 tools/assets/import-glb.py tools/assets/models.json js/assets.js`.

## Photographic materials (textures)

`js/texdata.js` is generated by `tools/assets/bake-textures.py` from the materials listed in
`tools/assets/textures.json`, downloaded by `tools/assets/fetch-textures.py`. Each material
becomes three data URIs: a colour map (512²), a normal map (320², GL convention, amplified to
compensate for the detail lost in tiling) and a roughness map (128²). The game paints the colour
map as the base layer of a texture and its own detail on top, and feeds the normal and roughness
to the shader.

All materials come from **ambientCG** (https://ambientcg.com) and are released under
**CC0 1.0 Universal** (public domain dedication): no attribution is required, but it is given
here gladly. The materials used are listed in `tools/assets/textures.json`.

To regenerate:

    pip install pillow numpy
    python3 tools/assets/fetch-textures.py /tmp/texcache          # downloads every material in the spec
    python3 tools/assets/bake-textures.py  /tmp/texcache js/texdata.js
